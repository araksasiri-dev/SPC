📋 Git Two Machines Checklist

✅ ก่อนเริ่ม: สิ่งที่ต้องเตรียม

#รายการสถานะหมายเหตุ
1ติดตั้ง Git บนเครื่องที่ 2☐winget install Git.Git
2ตั้งชื่อผู้ใช้ (เหมือนเครื่อง 1)☐git config --global user.name "ชื่อคุณ"
3ตั้งอีเมล (เหมือนเครื่อง 1)☐git config --global user.email "email@example.com"
4ตรวจสอบการตั้งค่า☐git config --list
5สร้าง SSH Key (optional)☐ssh-keygen -t ed25519 -C "email@example.com"
6เพิ่ม SSH Key ใน GitHub☐Settings → SSH and GPG keys

✅ ขั้นตอนการทำงานประจำวัน

A. ตอนเริ่มงาน

#คำสั่งสถานะ
1cd C:\SPC☐
2git pull☐
3เริ่มทำงาน☐

B. ตอนเสร็จงาน

#คำสั่งสถานะ
1git status☐
2git add .☐
3git commit -m "ข้อความ"☐
4git push☐

✅ คำสั่งลัดที่ใช้บ่อย

คำสั่งความหมาย
git statusดูสถานะ (ใช้บ่อยสุด)
git pullดึงงานล่าสุด
git add .เตรียมส่งทุกไฟล์
git commit -m "..."บันทึก
git pushส่งขึ้น GitHub
git log --oneline -5ดูประวัติ 5 รายการล่าสุด

✅ สูตรสำเร็จ

git pull        # 1. ดึงงานล่าสุด
git add .       # 2. เตรียมไฟล์
git commit -m "ทำอะไร"  # 3. บันทึก
git push        # 4. อัปโหลด

คาถา: "ก่อนทำอะไร pull ก่อน, เสร็จแล้ว push ทุกที"
