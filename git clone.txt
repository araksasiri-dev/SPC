🎯 git clone คือคำสั่งที่ใช้สำหรับ "ดาวน์โหลด" หรือ "คัดลอก" โค้ดทั้งหมดจาก GitHub มาไว้ในเครื่องของเรา เหมือนกับการ "โหลดโปรเจค" ครั้งแรกนั่นเองครับ

เปรียบเทียบให้เข้าใจง่ายๆ:

git pull = "อัปเดต" เอาเฉพาะส่วนที่เปลี่ยนแปลง (ใช้เมื่อมีโค้ดในเครื่องอยู่แล้ว)

git clone = "โหลดครั้งแรก" เอาทุกอย่างมาใหม่หมด (ใช้เมื่อยังไม่มีโค้ดในเครื่อง)

🖥️ ตัวอย่างการใช้งาน
สมมติว่าคุณไปทำงานที่เครื่องใหม่ (หรือเพื่อนร่วมทีมต้องการเอาโค้ดไปใช้)

เปิด Command Prompt หรือ Terminal แล้วพิมพ์:

bash
git clone https://github.com/arakasiri-dev/SPC.git
เมื่อรันแล้ว ระบบจะดาวน์โหลดทุกไฟล์ใน Repository SPC มาสร้างเป็นโฟลเดอร์ชื่อ SPC บนเครื่องคุณทันที! (เหมือนกับการก็อบปี้โปรเจคทั้งก้อนมาไว้ในเครื่อง)

📂 หลังจาก Clone เสร็จ
bash
cd SPC   # เข้าไปในโฟลเดอร์
dir      # ดูไฟล์ทั้งหมด
คุณจะเห็นโค้ดทุกไฟล์ที่เราอัปโหลดไปไว้บน GitHub อยู่ในเครื่องคุณแล้ว (ยกเว้นไฟล์ Secret ที่อยู่ใน .gitignore อย่าง credentials.json, token.pickle, และ users.db)

🔐 หลังจาก Clone ต้องทำอะไรต่อ?
เอาไฟล์ Secret กลับมาใส่

credentials.json

token.pickle

users.db (หรือไฟล์ฐานข้อมูล)

.env

ติดตั้ง Dependencies (Library ที่ต้องใช้)

bash
pip install -r requirements.txt
รันระบบตามปกติ

bash
robot register_users_gmail.robot
📊 สรุปความแตกต่าง
คำสั่ง	ใช้เมื่อ	ดึงข้อมูล
git clone	ยังไม่มีโปรเจคในเครื่อง	ดาวน์โหลดทั้งหมด (ครั้งแรก)
git pull	มีโปรเจคในเครื่องแล้ว	อัปเดตเฉพาะส่วนที่เปลี่ยนแปลง
✅ สรุปสั้นๆ
git clone = โหลดโปรเจคครั้งแรก
git pull = อัปเดตโปรเจคที่โหลดไว้แล้ว

นอกจากนี้ git clone ยังเป็นการ "ก็อบปี้" โค้ดจาก GitHub มาใช้บนเครื่องของเรา (หรือส่งต่อให้เพื่อนร่วมทีม) ได้อีกด้วยครับ 🚀
